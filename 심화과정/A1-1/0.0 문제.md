# 이커머스 멀티모달 데이터 분석 파이프라인 구축

## 1. 미션 소개

데이터 분석은 AI 모델링의 출발점이다. 알고리즘이 정교하더라도 데이터를 제대로 이해하지 못하면 의미 있는 결과를 낼 수 없다. 현업 데이터에는 숫자, 텍스트, 범주, 이미지 등 다양한 유형이 섞여 있으므로 이를 하나의 분석 흐름으로 통합하는 능력이 중요하다.

이 미션은 특정 산업에 국한되지 않는 공통 역량인 멀티모달 전처리, 이상치 탐지, 파이프라인 모듈화, 고객 세분화를 기르는 것을 목표로 한다. 이커머스 상품 데이터를 예시로 사용하지만, 관련 기술은 에너지·헬스케어 등 다른 도메인에도 전이할 수 있다.

상품명(텍스트), 가격(수치), 카테고리(범주), 등록일(날짜), 상품 이미지(배열)를 다룬다. NumPy 벡터 연산으로 이미지 데이터를 수치화하고, Pandas로 탐색적 데이터 분석(EDA)과 통계 분석을 수행한다. 시각화를 통해 비즈니스 인사이트를 도출하고, RFM(Recency, Frequency, Monetary) 분석으로 고객을 세분화해 전략을 제안한다.

### 반드시 수행할 핵심 과제

1. 수치·텍스트·이미지 배열을 NumPy 벡터 연산으로 통합 처리하는 파이프라인을 클래스로 구축한다.
2. IQR 이상치 탐지, 그룹별 결측치 대치, 6종 시각화를 포함한 EDA를 수행한다.
3. RFM 분석으로 고객을 4개 이상 세그먼트로 분류하고, 데이터에 근거한 비즈니스 전략을 제안한다.

## 4. 기능 요구 사항

### 4.1 데이터 로드 및 기본 탐색

- 1,000건 이상, 8개 이상 컬럼을 가진 이커머스 데이터셋을 사용한다.
- 수치형·범주형·날짜형·이미지 배열 중 3가지 이상의 데이터 유형을 포함한다.
- `info()`, `describe()`, `head()`를 이용해 데이터 구조를 파악하고 Markdown으로 해석한다.
- RFM 거래 데이터에는 최소 `customer_id`, `order_date`, `amount`(또는 `price × qty`) 컬럼이 있어야 한다.
- Recency 기준일은 데이터의 최종 거래일 또는 명시한 분석 기준일로 정의한다.
- 해석에는 수치 근거 1개 이상과 시사점 1문장 이상을 포함한다.

### 4.2 분석 파이프라인 모듈화(OOP)

분석 로직을 `DataAnalyzer` 클래스로 구현한다. 최소 다음 메서드를 포함한다.

- `load_data()`
- `handle_missing_values()`
- `detect_outliers()`
- `calculate_rfm()`

이상치 임계값, 결측치 대치 전략 등 주요 파라미터는 메서드 인자로 받는다.

### 4.3 멀티모달 피처 엔지니어링

**이미지 데이터**
- NumPy로 각 이미지의 평균(Mean)과 표준편차(Std)를 계산해 새 컬럼으로 추가한다.
- 이미지별 반복문(for loop) 대신 가능한 경우 배열 연산을 활용한다.

**텍스트 데이터**
- 상품명에서 단어 수(Word Count) 또는 문자열 길이를 계산해 파생 변수를 추가한다.

### 4.4 결측치 및 이상치 처리

- 결측치 현황을 파악한다.
- GroupBy 통계를 활용한 그룹별 대치 로직을 최소 1가지 적용한다.
- IQR 방식의 이상치 탐지 로직을 직접 함수로 구현한다.
- 이상치 처리 전후의 분포 변화를 시각화한다.

### 4.5 통계 분석

- 주요 수치형 변수의 평균, 중앙값, 표준편차, 사분위수를 계산하고 해석한다.
- 최소 2쌍 이상의 변수에 대해 상관계수를 계산하고 해석한다.
- 모든 해석에는 수치 근거 1개 이상과 시사점 1문장 이상을 포함한다.

### 4.6 시각화

다음 6가지 유형의 차트를 각각 1개 이상 작성한다. 모든 차트에는 제목과 축 레이블을 포함한다.

| 차트 유형 | 분석 목적 예시 |
|---|---|
| 히스토그램 | 수치형 변수의 분포 |
| 박스플롯 | 이상치 처리 전후 비교 |
| 막대그래프 | 범주별 빈도 또는 RFM 세그먼트별 고객 수 |
| 히트맵 | 상관행렬 또는 RFM 세그먼트 분포 |
| 산점도 | 두 수치형 변수의 관계 |
| 라인차트 | 월별 매출 등 시계열 추세 |

### 4.7 RFM 기반 고객 세분화

- 거래 데이터로 고객별 Recency, Frequency, Monetary 지표와 점수를 계산한다.
- VIP, Loyal, New, Churned 등의 예시를 참고해 고객을 최소 4개 그룹으로 세분화한다.
- 각 그룹의 특징을 분석하고 세분화 결과에 근거한 비즈니스 인사이트를 README에 작성한다.
- 세그먼트 규칙과 Recency 기준일을 명확하게 문서화한다.

**인사이트 2 — VIP 고객 유지**
- **근거:** VIP 그룹의 평균 구매 빈도는 월 4.2회이고 전체 매출의 45%를 차지한다.
- **실행:** VIP 고객에게 전용 멤버십 혜택을 제공해 충성도를 높이고 이탈을 방지한다.
- **검증:** VIP 이탈 시 매출 감소 규모를 시뮬레이션할 필요가 있으며, 현재 데이터만으로는 정확한 고객 생애 가치(LTV)를 산출하기 어렵다.
