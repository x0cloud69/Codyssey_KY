# IQR 방식 이상치 탐지 요약

## 1. 한 줄 정의
데이터의 **가운데 50% 구간(Q1~Q3)** 에서 IQR의 1.5배 넘게 벗어난 값을 이상치 **후보**로 보는 방법 (튜키 울타리, Tukey's fences).

## 2. 용어

| 용어 | 의미 | describe() 항목 |
|---|---|---|
| Q1 | 줄 세웠을 때 25% 지점의 값 (평균 아님, 경계값) | 25% |
| Q3 | 75% 지점의 값 | 75% |
| IQR | Q3 − Q1, 가운데 50%가 퍼진 폭 | - |

## 3. 공식

```
lower = Q1 − 1.5 × IQR
upper = Q3 + 1.5 × IQR
이상치: 값 < lower  또는  값 > upper
```

```
     lower        Q1      Q3        upper
 ←이상치→ |---- 정상 범위 ----| ←이상치→
```

## 4. 코드

```python
def find_iqr_outliers(series, multiplier=1.5):
    q1 = series.quantile(0.25)
    q3 = series.quantile(0.75)
    iqr = q3 - q1
    lower = q1 - multiplier * iqr
    upper = q3 + multiplier * iqr
    mask = (series < lower) | (series > upper)
    return mask, lower, upper
```

- `series`: 컬럼 하나 (예: `df["price"]`)
- `mask`: 이상치면 True인 Series → `df[mask]`로 해당 행 확인

## 5. 근거: 관례로 굳어진 기준
- 1977년 John Tukey가 제안한 경험적 기준이며, 수학적으로 유도된 값이 아님.
- 1.5는 정규분포에서 약 0.7%만 이상치로 표시되도록 고른 절충값 (1.0은 과다, 3.0은 극단값만).
- 평균·std는 이상치에 끌려가지만 사분위수는 안정적이라 치우친 데이터에 적합.
- `multiplier`는 목적에 따라 조절 가능 (1.5 보통, 3.0 엄격).

## 6. 적용 예: price (A1-1 데이터)

| 항목 | 값 |
|---|---|
| Q1 / Q3 | 39.9 / 134.9 |
| IQR | 95 |
| lower | −102.6 (가격이 음수가 아니므로 하한 이상치 없음) |
| upper | 277.4 |
| max | 6735 (상한을 크게 초과) |

- 평균(120.65) > 중앙값(74.99): 오른쪽으로 치우친 분포.
- 277.4 초과 값이 모두 오류는 아님 (실제 고가 상품 가능).

## 7. 주의
- 이상치 **후보**일 뿐 오류 판정이 아니다. 삭제 전에 건수와 비율을 확인할 것.
- 치우친 분포는 이상치가 많이 잡히는 경향이 있다. 로그 변환 후 적용하거나 도메인 기준을 병행한다.
- 처리 방법: 유지 / 삭제 / 상한값으로 자르기(winsorize) / 로그 변환.
