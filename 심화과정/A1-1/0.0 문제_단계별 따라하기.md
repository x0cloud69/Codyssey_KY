## 6단계. 결측치 처리하기

결측치는 비어 있는 값이다. 모든 결측치를 무조건 0으로 바꾸면 안 된다. 가격이 비어 있는 것과 주문 수량이 0인 것은 의미가 다르기 때문이다.

### 6-1. 결측치 확인

```python
missing = df.isna().sum()
print(missing[missing > 0].sort_values(ascending=False))
```

### 6-2. 그룹별 대치 적용

예를 들어 상품 가격이 비어 있다면, 전체 평균 대신 같은 카테고리의 중앙값으로 채우는 방법을 고려할 수 있다.

```python
# 실제 데이터의 카테고리·가격 컬럼명에 맞춰 수정한다.
df["price"] = df["price"].fillna(
    df.groupby("category")["price"].transform("median")
)
```

이 코드는 `category`와 `price`라는 컬럼이 있을 때만 그대로 실행할 수 있다. 실제 컬럼명이 다르면 바꾼다. 그룹 자체의 값이 모두 비어 있어 대치되지 않은 값은 별도로 확인하고, 해당 행을 유지할지 제외할지 이유를 기록한다.

### 6-3. 처리 결과 확인


## 7단계. IQR 방식으로 이상치 찾기

이상치는 유난히 크거나 작은 값이다. 이상치가 항상 잘못된 데이터인 것은 아니다. 실제 고가 상품이나 대량 주문일 수도 있으므로 먼저 찾고, 이유를 검토한 다음 처리 여부를 결정한다.

IQR은 3사분위수(Q3)에서 1사분위수(Q1)를 뺀 값이다.

- 하한 = Q1 − 1.5 × IQR
- 상한 = Q3 + 1.5 × IQR

### 7-1. 이상치 탐지 함수 만들기

```python
def find_iqr_outliers(series, multiplier=1.5):
    q1 = series.quantile(0.25)
    q3 = series.quantile(0.75)
    iqr = q3 - q1
    lower = q1 - multiplier * iqr
    upper = q3 + multiplier * iqr
    mask = (series < lower) | (series > upper)
    return mask, lower, upper
```

### 7-2. 실제 컬럼에 적용

```python
mask, lower, upper = find_iqr_outliers(df["price"].dropna())
print("하한:", lower)
print("상한:", upper)
print("탐지된 이상치 수:", mask.sum())
```

위 코드는 결측치를 제외한 Series에서 마스크를 계산한다. 원본 DataFrame의 행과 정확히 대응하는 결과가 필요하면 아래처럼 적용한다.

```python
price = df["price"]
q1 = price.quantile(0.25)
q3 = price.quantile(0.75)
iqr = q3 - q1
lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr
outlier_mask = price.notna() & ((price < lower) | (price > upper))
outliers = df.loc[outlier_mask]
print(outliers.head())
```

### 7-3. 처리 전후 비교

우선 이상치가 표시된 행을 살펴보고 오류인지 실제 고액 거래인지 판단한다. 근거 없이 행을 삭제하지 않는다. 이상치를 유지한 분석과 제외한 분석을 비교하는 것도 가능하다.

## 11단계. RFM으로 고객 세분화하기

RFM은 고객의 구매 행동을 세 가지 관점에서 평가한다.

- **Recency (R):** 기준일로부터 마지막 구매일까지 지난 일수. 일반적으로 작을수록 최근에 구매했다.
- **Frequency (F):** 고객의 구매 횟수. 일반적으로 많을수록 자주 구매한다.
- **Monetary (M):** 고객의 총 구매 금액. 일반적으로 클수록 지출이 많다.

### 11-1. 거래 데이터 확인

거래 데이터에 다음 정보가 있어야 한다.

- 고객 식별자: 예) `customer_id`
- 주문 날짜: 예) `order_date`
- 구매 금액: 예) `amount`

구매 금액 컬럼이 없다면 가격과 수량을 곱해 거래 금액을 만들 수 있는지 확인한다. 실제 데이터에 맞춰 컬럼명을 바꾼다.

### 11-2. RFM 지표 계산

```python
import pandas as pd

orders["order_date"] = pd.to_datetime(orders["order_date"], errors="coerce")
orders = orders.dropna(subset=["customer_id", "order_date", "amount"])

reference_date = orders["order_date"].max() + pd.Timedelta(days=1)

rfm = orders.groupby("customer_id").agg(
    last_order=("order_date", "max"),
    frequency=("order_date", "count"),
    monetary=("amount", "sum"),
)

rfm["recency"] = (reference_date - rfm["last_order"]).dt.days
rfm = rfm[["recency", "frequency", "monetary"]]
display(rfm.head())
```

이 예시는 각 행을 거래 1건으로 간주한다. 한 주문이 여러 행으로 나뉜 데이터라면 주문 ID를 확인해 Frequency를 고유 주문 수로 계산해야 한다. 취소·환불·반품을 포함하는지도 결정해 문서화한다.

### 11-3. 점수와 세그먼트 만들기

아래는 시작용 예시 규칙이다. 데이터에 따라 점수 구간을 조정하고 이유를 기록한다.

```python
# qcut은 값이 한쪽에 몰려 있거나 같은 값이 너무 많으면 오류가 날 수 있다.
# 오류가 나면 구간 수를 줄이거나 rank(method="first") 등 대안을 검토한다.
rfm["R_score"] = pd.qcut(
    rfm["recency"].rank(method="first"), 4, labels=[4, 3, 2, 1]
).astype(int)
rfm["F_score"] = pd.qcut(
    rfm["frequency"].rank(method="first"), 4, labels=[1, 2, 3, 4]
).astype(int)
rfm["M_score"] = pd.qcut(
    rfm["monetary"].rank(method="first"), 4, labels=[1, 2, 3, 4]
).astype(int)

def assign_segment(row):
    if row["R_score"] >= 3 and row["F_score"] >= 3 and row["M_score"] >= 3:
        return "VIP"
    if row["R_score"] >= 3 and row["F_score"] >= 2:
        return "Loyal"
    if row["R_score"] >= 3 and row["F_score"] == 1:
        return "New_or_Recent"
    if row["R_score"] <= 2:
        return "At_Risk_or_Churned"
    return "Other"

rfm["segment"] = rfm.apply(assign_segment, axis=1)
display(rfm.groupby("segment").agg(
    customers=("segment", "size"),
    avg_recency=("recency", "mean"),
    avg_frequency=("frequency", "mean"),
    avg_monetary=("monetary", "mean"),
))
```

이 분류는 학습용 예시다. 실제 사업에서 “신규 고객”과 “이탈 고객”을 정확히 나누려면 고객 가입일, 과거 구매 주기, 이탈 정의 등의 추가 정보가 필요할 수 있다. 보고서에는 사용한 규칙과 한계를 명시한다.

### 11-4. 최소 4개 그룹 해석하기

각 세그먼트에 대해 다음을 표로 정리한다.

| 세그먼트 | 고객 수 | 평균 Recency | 평균 Frequency | 평균 Monetary | 추천 행동 |
|---|---:|---:|---:|---:|---|
| VIP | 실제 계산값 | 실제 계산값 | 실제 계산값 | 실제 계산값 | 우수 고객 유지 |
| Loyal | 실제 계산값 | 실제 계산값 | 실제 계산값 | 실제 계산값 | 재구매·멤버십 |
| New_or_Recent | 실제 계산값 | 실제 계산값 | 실제 계산값 | 실제 계산값 | 첫 재구매 유도 |
| At_Risk_or_Churned | 실제 계산값 | 실제 계산값 | 실제 계산값 | 실제 계산값 | 이탈 원인 확인·재활성화 |

표의 수치는 예시로 채우지 말고 직접 계산한 결과를 넣는다.

### 12-1. 파일 만들기

`src/pipeline.py` 파일을 만든다. 아래는 기본 구조이며, 각 메서드에 앞 단계에서 검증한 코드를 옮겨 완성한다.

```python
from pathlib import Path
import numpy as np
import pandas as pd


class DataAnalyzer:
    def __init__(self, data_path):
        self.data_path = Path(data_path)
        self.df = None

    def load_data(self):
        self.df = pd.read_csv(self.data_path)
        return self.df

    def handle_missing_values(self, group_col, target_col):
        if self.df is None:
            raise ValueError("먼저 load_data()를 실행하세요.")

        self.df[target_col] = self.df[target_col].fillna(
            self.df.groupby(group_col)[target_col].transform("median")
        )
        return self.df

    def detect_outliers(self, column, multiplier=1.5):
        if self.df is None:
            raise ValueError("먼저 load_data()를 실행하세요.")

        series = self.df[column]
        q1 = series.quantile(0.25)
        q3 = series.quantile(0.75)
        iqr = q3 - q1
        lower = q1 - multiplier * iqr
        upper = q3 + multiplier * iqr
        return self.df.loc[
            series.notna() & ((series < lower) | (series > upper))
        ]

    def calculate_rfm(
        self, customer_col, date_col, amount_col, reference_date=None
    ):
        if self.df is None:
            raise ValueError("먼저 load_data()를 실행하세요.")

        data = self.df.copy()
        data[date_col] = pd.to_datetime(data[date_col], errors="coerce")
        data = data.dropna(subset=[customer_col, date_col, amount_col])

        if reference_date is None:
            reference_date = data[date_col].max() + pd.Timedelta(days=1)

        rfm = data.groupby(customer_col).agg(
            last_order=(date_col, "max"),
            frequency=(date_col, "count"),
            monetary=(amount_col, "sum"),
        )
        rfm["recency"] = (reference_date - rfm["last_order"]).dt.days
        return rfm[["recency", "frequency", "monetary"]]
```

**중요:** 이 코드는 기본 골격이다. `handle_missing_values()`는 그룹 컬럼과 대상 컬럼에 실제 데이터의 컬럼명을 넣어 호출해야 한다. RFM을 계산할 때는 거래 데이터로 별도의 `DataAnalyzer` 인스턴스를 만들거나, 클래스가 파일 형식을 선택할 수 있도록 확장한다. 클래스에 이미지 피처와 텍스트 피처 생성 메서드도 추가해 과제 요구사항을 모두 충족한다.

## 14단계. README와 비즈니스 인사이트 작성하기

`README.md`에는 다음 항목을 작성한다.

```markdown
# 이커머스 멀티모달 데이터 분석

## 프로젝트 개요
## 분석 목표
## 데이터 출처 및 컬럼 설명
## 실행 환경 및 설치 방법
## 실행 방법
## 분석 방법
## 주요 결과
## 비즈니스 인사이트
## 한계 및 추가 분석
## 폴더 구조
```

### 인사이트는 최소 3개 작성

각 인사이트에는 다음 3가지가 반드시 포함되어야 한다.

1. **근거:** 실제 분석 수치나 차트 결과
2. **실행:** 누구에게 무엇을 할 것인지, 기대 효과는 무엇인지
3. **검증:** 아직 모르는 점, 추가 데이터 또는 실험으로 확인할 사항

예를 들어 “VIP 고객을 관리해야 한다”만 쓰면 부족하다. 실제 VIP 고객 수나 매출 비중을 근거로 제시하고, 어떤 유지 전략을 실행할지 적고, 전략의 효과를 어떻게 검증할지 설명한다. 수치를 만들어내지 말고 분석 결과에서 가져온다.

### 실행 방법 예시

```powershell
python -m pip install -r requirements.txt
jupyter notebook
```

데이터 파일 경로와 실제 실행 방식이 위 예시와 다르면 README를 실제 프로젝트에 맞게 수정한다.

## 16단계. GitHub에 올리고 제출하기

### 16-1. Git 저장소 확인

Git이 설치되어 있고 저장소를 이미 내려받았다면 프로젝트 폴더에서 다음을 실행한다.

```powershell
git status
```

변경된 파일이 표시되는지 확인한다. 저장소가 아직 Git으로 관리되지 않는다면 과제에서 안내한 GitHub 저장소를 먼저 준비한다.

### 16-2. 올리면 안 되는 파일 확인

원본 데이터에 개인정보가 있거나 배포가 허용되지 않는다면 공개 저장소에 올리지 않는다. 대용량 이미지와 원본 데이터는 라이선스와 저장소 정책을 확인한다. 가상환경 `.venv/`는 저장소에 올리지 않는 것이 일반적이다.

프로젝트 루트에 `.gitignore` 파일을 만들고 아래 항목을 넣을 수 있다.

```gitignore
.venv/
__pycache__/
.ipynb_checkpoints/
.env
```

### 16-3. 변경 사항 커밋 및 푸시

```powershell
git add src/pipeline.py notebooks/analysis_report.ipynb README.md requirements.txt .gitignore
git commit -m "Complete A1-1 ecommerce data analysis"
git push
```

이 명령은 Git 저장소가 이미 연결되어 있고 브랜치와 인증이 설정된 경우에 사용한다. 오류가 나면 오류 내용을 확인하고 해결한다. 무작정 `--force` 옵션을 사용하지 않는다.

### 16-4. 최종 제출물 확인

GitHub 웹사이트에서 파일이 실제로 올라갔는지 확인한다.

```text
src/pipeline.py
notebooks/analysis_report.ipynb
README.md
requirements.txt
```
